# O&K報告書

株式会社オーアンドケーの現場で使う報告書アプリです。スマホのブラウザで GitHub Pages のURLを開いて使います（ホーム画面に追加でき、一度開けば電波のない現場でも使えます）。写真とデータは各端末の中にだけ保存されます。

| アプリ | 場所 | 内容 |
| --- | --- | --- |
| O&K報告書 | `index.html` | 施工前・中・後の重ね撮り写真、施工看板、チェックリスト、作業完了報告書（店名・店番・作業項目チェック・特記事項・お客様ご署名）、報告書PDFの保存・共有、報告書フォルダ、テンプレート |
| O&K看板写真（簡易版） | `simple/index.html` | 重ね撮り写真と施工看板、備考付きの写真報告書PDF、写真のzip保存 |
| 作業報告書（アプリ入力版） | `sagyo.html` | 紙の作業報告書をスマホで入力、お客様サイン、画像・PDFの保存・共有、印刷 |
